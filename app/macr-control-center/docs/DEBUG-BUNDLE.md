# Debug Bundle Export

## Contents
- `last-launcher.json` — structured launcher result
- `last-stdout.log` / `last-stderr.log` — truncated logs
- `doctor.json` — macr-doctor report
- `verify.json` — platform verify report
- `d3d.json` — D3D replay report
- `git-diff-stat.txt` — repo changes
- `manifest.json` — bundle index with sizes and inclusion status

## Size Limits
By default logs over 2 MiB are truncated. Enable "Include Full Logs" in settings to export everything.
