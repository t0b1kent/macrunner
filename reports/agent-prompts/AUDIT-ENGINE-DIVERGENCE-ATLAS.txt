ЗАДАЧА (для каждого файла графического стека):
1. Достань upstream Wine 11.0 версию файла (git tag wine-11.0, github wine-mirror/wine).
2. Diff наш vs сток. Для каждого MACRUNNER-блока:
   - Что изменено (одна строка).
   - Зачем (из комментария/журнала ENGINE-CHANGE-JOURNAL / коммитов).
   - Классификация: ESSENTIAL (реальная macOS/HyperBridge нужда, сток падает без неё)
     | INTEGRATION (winemac.drv/CG glue) | BAND-AID (косметика/обход, сток работает
     без) | EXPERIMENTAL (попытка фикса, возможно вредная).
   - Работает ли сток без нашей правки? (гипотеза/если проверяемо).
3. Выход: reports/engine-audit/WINE-DIVERGENCE-ATLAS.md — таблица:
   File | MACRUNNER-блок (line) | Что | Зачем | Класс | Сток-без-неё | Риск-регресса.
4. Сводка: какие патчи — кандидаты на откат к стоку (BAND-AID/EXPERIMENTAL), какие
   беречь (ESSENTIAL/INTEGRATION).
