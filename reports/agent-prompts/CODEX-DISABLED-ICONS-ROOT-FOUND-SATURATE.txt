ЦЕПОЧКА (наш дерево, не upstream):
1. comctl32/toolbar.c:837-844 — disabled-кнопка: нет himlDis (Notepad++ его не
   ставит) → fallback на DEFAULT imagelist с draw_masked=TRUE.
2. toolbar.c:877-878 — draw_masked → TOOLBAR_DrawMasked().
3. TOOLBAR_DrawMasked (toolbar.c:736-763) — для 32bpp С alpha берёт ILS_ALPHA
   (строка 758-763, "keeps hue"). НО иконки тулбара = zero-alpha + mono-mask →
   has_alpha=FALSE → НЕ попадают в ILS_ALPHA → проваливаются в ILS_SATURATE.
4. imagelist.c:1523-1531 — ILS_SATURATE grayscale (gray = R*299+G*587+B*114)/1000;
   строка 1530: if (has_alpha) gray = gray*alpha/255. Для zero-alpha+mask семьи это
   даёт ПЛОСКУЮ серую заливку вместо затенённого силуэта = пустые квадраты на экране.
