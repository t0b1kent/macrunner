# Архитектура уровня магазина для Mac‑приложения без Rosetta

## Введение

Чтобы запускать Windows‑игры на Apple Silicon без Rosetta, вы уже собрали x86₆₄→ARM64 транслирующий слой и ARM64‑Wine 11 с преобразованием DirectX → Metal. Следующий шаг — организовать скачивание, аутентификацию и лицензионную проверку игр. Ниже рассматриваются существующие решения для Epic Games Store (Legendary/Heroic/Mythic), Steam и GOG, а также альтернативные магазины. Для каждой системы описано, что работает нативно, что выполняется под Wine, какие ограничения накладывают DRM/античит, и какие open‑source‑компоненты доступны вместе с их лицензиями.

## 1 Epic Games Store: модель Legendary/​Heroic/​Mythic

### Legendary: нативный клиент Epic

**Как работает.** Legendary — это свободный Python‑CLI, полностью заменяющий официальный Epic Games Launcher. Пользователь аутентифицируется через Epic OAuth: команда `legendary auth` открывает страницу входа в браузере, пользователь логинится и копирует возвращённый код в терминал【590711641399071†L186-L211】. После этого Legendary может:

- получать список игр и манифесты;
- скачивать и устанавливать игры и DLC, включая Windows‑сборки, поддерживая дельта‑патчи и возобновление загрузки【590711641399071†L41-L63】;
- запускать игры, требующие сетевой аутентификации, синхронизировать облачные сохранения, экспортировать/импортировать установленные игры【590711641399071†L41-L63】.

Приложение работает нативно на macOS и Linux; только скачанный `.exe` запускается под Wine, поэтому клиент и его обновления не нуждаются в эмуляции.

**Ограничения.** На момент 2026 г. Legendary не реализует всех возможностей официального лаунчера. Для доступа к Epic Online Services (EOS) Overlay и отображения достижений требуется отдельное включение и создание линков в каждом префиксе. Вики Epic Games Store отмечает, что системной настройки для EOS нет, и оверлей необходимо активировать для конкретной игры【938232710473745†L287-L312】. В релизе 0.20.27 добавлена поддержка EOS Overlay с командами `legendary eos-overlay install/enable` (Linux)【129911126985115†L23-L42】; по состоянию на 2026 г. полнота работы на macOS ещё ограничена. Legendary также не запускает античит‑сервисы, поэтому игры с EAC, BattlEye или другими kernel‑драйверами не работают (см. раздел «Kill filter»).

**Лицензия.** Legendary распространяется под лицензией GPL 3.0【549556401720134†L1083-L1086】, поэтому для использования в коммерческом приложении придётся либо предоставить исходные модификации, либо рассмотреть возможность взаимодействия через отдельный процесс (см. рекомендации).

### Heroic Games Launcher: графическая оболочка

Heroic — открытый GUI‑лаунчер на Electron и React, использующий Legendary для работы с Epic Games и gogdl для GOG. Статья Linux Gaming Wiki указывает, что Heroic управляет несколькими версиями Wine/Proton, поддерживает уникальные префиксы для каждой игры и передаёт команды в Legendary【62078261052925†L7-L13】. Разработчики Heroic подтверждают, что основная работа по загрузке и обновлению игр выполняется Legendary и Wine; Heroic лишь отправляет команды и предоставляет удобный интерфейс【189243618483494†L164-L170】. В версии 2.4.0 была добавлена поддержка GOG‑cloud save, EOS Overlay, а также установка EAC/BattlEye runtime для игр, где разработчики включили поддержку【868822865909971†L69-L90】.

**Исполнение.** Сам Heroic работает нативно на macOS; он вызывает Legendary (CLI) для скачивания контента и запускает `.exe` игры под Wine/Proton (в Linux/Steam Deck) или через Game Porting Toolkit (на macOS). Таким образом, уровень магазина отделён от уровня исполнения.

**Лицензия.** Проект GPL‑3.0, что требует соблюдения условий при встраивании.

### Mythic App: macOS‑ориентированный лаунчер

Mythic — открытый нативный лаунчер для macOS 14+, использующий собственную реализацию Apple Game Porting Toolkit. Описание на сайте подчёркивает поддержку Windows‑игр (DX9–DX12), интеграцию с Epic Games, возможность ручного импорта и управление библиотекой【249926485853381†L20-L58】. README проекта перечисляет функциональность: поддержка Windows‑игр через GPTK, поддержка Epic Games (через Legendary), добавление локальных игр, управление контейнерами и Discord‑интеграция【266229935437046†L20-L45】. Релиз 0.6.0 отметил «полный пересмотр архитектуры игр» — введены типы Epic, локальных и Steam‑игр, создан постоянный `GameDataStore`, улучшено управление контейнерами и `WineWrapper`, а Legendary интегрирован как модуль【237278008230547†L42-L94】. Mythic так же, как Heroic, скачивает игры нативно и запускает `.exe` под GPTK/Wine. Лицензия Mythic — GPL 3.0【298034713693400†L337-L340】.

### Ограничения Epic‑модели

- **Античиты и ядро.** Игры с Easy Anti‑Cheat (не EOS‑версией), BattlEye, Riot Vanguard, Ricochet или nProtect GameGuard используют kernel‑драйверы; Wine не может загружать Windows‑драйверы, поэтому такие игры не будут работать【244106850201846†L236-L250】【58001186922483†L36-L46】【566449039980901†L78-L93】. Даже если разработчики активируют EAC для Proton, требуется переход на EOS‑версию и дополнительная авторизация на сервисах Epic, что осложняет внедрение【345470980233402†L28-L47】.
- **EOS‑зависимые функции.** Достижения и социальные функции Epic работают только при включении EOS Overlay, которое ещё не полностью поддерживается на macOS【938232710473745†L287-L312】.
- **Региональные DRM/конент.** Хотя Epic не использует собственную DRM, отдельные игры могут иметь сторонний DRM или онлайн‑требования; в таких случаях нативная загрузка не снимает ограничений.

## 2 Steam: возможен ли «Legendary для Steam»?

### Нативные средства загрузки

**SteamCMD.** Valve предоставляет командный клиент SteamCMD, который может работать на macOS (устанавливается через Homebrew). Руководство Swiss Mac User объясняет, что SteamCMD позволяет авторизоваться (поддерживая 2FA), задать папку установки и принудительно указать Windows‑платформу, выполнив команду `+@sSteamCmdForcePlatformType windows`【800304833068466†L45-L100】. Это позволяет скачать файлы Windows‑версии игры на Mac, несмотря на то что официальная Mac‑версия может отсутствовать【800304833068466†L15-L21】. FAQ сайта Mac Source Ports подтверждает: если вы владеете игрой в Steam, можно использовать SteamCMD, чтобы установить данные Windows‑версии на Mac и затем использовать их в портах【513442052203934†L66-L68】.

**DepotDownloader.** Альтернатива от сообщества — .NET‑утилита DepotDownloader. Readme проекта показывает, что программа кросс‑платформенная, устанавливается через Homebrew, и позволяет указывать целевую ОС (`-os windows`) и архитектуру (`-osarch 32/64`) для загрузки Windows‑депо. Аутентификация требует ввода логина; чтобы избежать повторной 2FA, предусмотрена опция `-remember-password`, сохраняющая токен, а для авторизации через мобильное приложение можно использовать параметр `-qr`【519813099269246†L74-L89】【519813099269246†L146-L149】. Она также поддерживает загрузку отдельных депо и манифестов【519813099269246†L90-L133】. DepotDownloader лицензирован под GPL v2【325853646653993†L0-L7】, что ограничивает его коммерческое использование.

### Проблемы DRM и Steamworks

Большинство игр в Steam используют библиотеку `steam_api(64).dll` для DRM и функциональности Steamworks. PCGamingWiki отмечает, что DRM‑free игры на Steam — это те, которые запускаются без клиента; таких игр мало, и их список составляется сообществом, так как Valve не маркирует их специально【66249133412282†L102-L122】. Блог об управлении цифровым наследством говорит, что лишь небольшое число DRM‑free игр на Steam запускается без лаунчера, тогда как «подавляющее большинство современных игр требует клиент Steam, который требует аккаунт и вход»【78663583553372†L96-L103】. Если игра требует Steam‑клиент, загруженные через SteamCMD файлы будут запускаться под Wine только при запущенном Windows‑клиенте (или если использовать неофициальные эмуляции Steam API, что юридически сомнительно). Поэтому модели «скачал нативно → запустил без клиента» применимы только к небольшому подмножеству игр.

### CrossOver/Whisky сегодня

Гайды по Whisky (официальный фронтэнд GPTK) советуют устанавливать Windows‑версию Steam внутри бутылки Wine. Это требует наличия Rosetta 2 и Game Porting Toolkit; пользователь загружает `SteamSetup.exe` и запускает его под Wine, затем устанавливает игры через Steam【332707186648149†L18-L44】. Автор отмечает, что старые игры на DX9, требующие AVX или kernel‑античит, могут не работать【332707186648149†L48-L61】. CrossOver использует аналогичный подход. Нативной загрузки без клиента Steam они не предлагают.

### Вывод по Steam

Нельзя построить полноценный «Legendary for Steam» без обхода DRM. Хоть SteamCMD/DepotDownloader позволяют скачивать Windows‑депо на Mac и подходят для DRM‑free игр, большинство игр всё равно требуют Steam‑клиент для проверки лицензий. Поэтому на практике вам придётся запускать Windows Steam под Wine (или использовать собственный ARM64‑Wine с x86₆₄ транслятором) для проверки лицензий и работы Steamworks. Нативный загрузчик можно использовать лишь как вспомогательный инструмент для DRM‑free игр и портов.

## 3 GOG, Amazon Games и itch.io

### GOG (Good Old Games)

GOG позиционирует себя как площадка, продающая только DRM‑free игры. В официальном блоге компания подчёркивает: она «полностью привержена предоставлять исключительно DRM‑free игры»; покупая игру на GOG, вы можете играть офлайн, делать резервные копии, устанавливать на неограниченное число устройств и решать, использовать ли клиент или запускать игру напрямую【772093841615899†L260-L268】. Игры поставляются как офлайн‑установщики или ZIP‑архивы. Heroic использует модуль `gogdl` для скачивания игр. Репозиторий gogdl имеет лицензию GPL‑3.0【906993204436813†L346-L352】.

**Вывод.** Для вашего приложения путь прост: скачивайте установщики нативно через официальные API или gogdl, распаковывайте их (например, через `innoextract`), затем запускайте `.exe` под Wine. DRM и лаунчер не требуются.

### Amazon Games / Prime Gaming

Неофициальный клиент **nile** позволяет авторизоваться в Amazon/Prime Gaming, скачивать игры и запускать их через Wine/Proton. Репозиторий nile описывает функции: вход в учётную запись, скачивание игр и их запуск под Wine/Proton; лицензия — GPL 3.0【387072678482925†L370-L378】. Проект относительно молодой; многие игры с Amazon используют DRM от Ubisoft или EA, что может требовать дополнительные клиенты. Поэтому модель подходит лишь для части библиотеки.

### itch.io

Для itch.io существует официальный CLI **butler**. Документация указывает, что butler использует open‑source движок wharf и выпускается под MIT‑лицензией【576132943269004†L630-L642】. Butler изначально предназначен для загрузки и загрузки билдов разработчиками, но может скачивать игры, на которые у пользователя есть права. Itch.io игры часто DRM‑free, поэтому после загрузки `.exe` их можно запускать напрямую под Wine. Поскольку лицензия MIT разрешает интеграцию, butler подходит для встраивания.

### Выводы и советы

1. **Epic Games** — оптимальный кандидат для нативного слоя. Legendary может быть встроен как отдельный модуль (общение через CLI / RPC), сохраняя GPL совместимость. Имейте в виду, что игры с kernel‑античитами работать не будут. Для GUI можно использовать собственный интерфейс или обернуть Legendary (как Heroic).

2. **Steam** — полноценный нативный клиент создать нельзя. Нативные загрузчики (SteamCMD/DepotDownloader) позволяют скачивать файлы, но большинство игр всё равно требуют Steam‑клиент для проверки лицензий. Поэтому либо ограничивайтесь DRM‑free играми, либо запускайте Windows Steam под Wine. Обход DRM с помощью эмуляторов Steam API нарушает условия Valve и не рассматривается. SteamCMD — проприетарный инструмент, а DepotDownloader имеет GPL‑2.0, что затрудняет коммерческую интеграцию.

3. **GOG** — идеальный вариант: игры DRM‑free, доступен модуль gogdl для загрузки, требующий только Wine для запуска. Для вашего приложения достаточно загрузить инсталлятор, распаковать его и запустить игру.

4. **Amazon Games / itch.io** — нишевые магазины. Nile и butler позволяют загрузить игры, но оба компонента GPL/​MIT. Продукт сможет поддерживать их, если есть спрос. Обратите внимание на сторонний DRM/античит.

### Открытые вопросы

- Список DRM‑free игр в Steam постоянно меняется и официально не публикуется. Чтобы поддержать нативную загрузку без клиента, нужно составить собственную базу.
- Легальная сторона использования SteamCMD/DepotDownloader в коммерческом приложении не ясна; необходимо изучить условия использования сервиса Steam.
- Полная поддержка EOS Overlay в Legendary/Heroic на macOS может измениться; следите за обновлениями.
- Mythic планирует поддержку Steam; детали имплементации пока не опубликованы. Следует проверить, будет ли использован SteamCMD или Windows‑Steam.
